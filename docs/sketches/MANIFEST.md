# Sketch Manifest

## Design Direction
Counterpoint's console should feel like mission control for one person: calm and Linear-like, built on Astryx's neutral theme (Figtree, warm greys, monochrome accent, light and dark).
Its first job is to answer "can I walk away?". After that come what needs the owner, then how much runway is left.
"Dark cockpit": when everything is normal the page stays quiet and grey; color appears only for exceptions (parked items, changed approvals, stopped runs).
Agents move the work and the owner only makes decisions. Any board is something you watch, never something you drag. Buttons appear only for decisions (approve, merge, retry, pick).

Round 2 added life without spending status colors: motion where something is actually happening, a timeline of the night, one big number per mode, and time-of-day ambience in the hero only. One non-status hue (Astryx purple) means "live".

## Reference Points
- Linear: triage inbox, keyboard-first, calm density, agents as delegates with visible state, "respect requests to disengage"
- Aviation "dark cockpit" panels: quiet when normal, lights only for exceptions
- Mission control: flight state, mission clock, Go/No-go before launch, debrief after landing
