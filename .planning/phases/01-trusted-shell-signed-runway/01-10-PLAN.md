## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → privileged prepare POST | Cross-site pages and local agents may try to drive it |
| in-memory cache → console status | Must never become authority |
| console preview → terminal signing | The owner signs what the terminal prints, not what the browser showed |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-47 | Tampering | POST …/approval | medium | mitigate | Session cookie + exact Origin + JSON content type (01-02 guards); the endpoint writes nothing and only previews |
| T-01-48 | Spoofing | approval status cache | high | mitigate | Cache keyed by host, tip, item and trusted fingerprint, emptied on start; every state comes from `verifyApprovalCommit` + digest comparison at the tip |
| T-01-49 | Repudiation | stale preview | medium | mitigate | Stale banner and disabled copy when the tip moves; the CLI re-derives and prints the statement and fingerprint before the passphrase regardless |
| T-01-SC | Tampering | npm/pnpm installs | high | mitigate | No new packages; frozen lockfile from 01-01 |
</threat_model>
