## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host repo config → diff/status commands | textconv, external diff and fsmonitor are repo-controlled |
| agent-written file contents → diff rendering | Untrusted text shown to the owner |
| diff endpoint → filesystem/git objects | Must not become an arbitrary-read endpoint |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-50 | Elevation | diff.ts | high | mitigate | `--no-ext-diff --no-textconv --no-index` through the clean-env runner (hooks/fsmonitor off, global/system config ignored) |
| T-01-51 | Elevation | uncommitted hint `git status` | high | mitigate | `-c core.fsmonitor=false`, `GIT_OPTIONAL_LOCKS=0`, clean env; working-tree ROADMAP read with O_NOFOLLOW as a regular file |
| T-01-52 | Information disclosure | GET …/diff | medium | mitigate | `path` must be in the item's change list (the gate-config row included); item and host ids validated; session required |
| T-01-53 | Tampering | ChangeViewPage | medium | mitigate | Diffs rendered as plain text in `CodeBlock` (no HTML); CSP `script-src 'self'` |
| T-01-54 | Denial of service | diff size | low | mitigate | 5,000-line cap with `truncated`, temp files removed in `finally`, reads capped by the reader's 5 MiB limit |
| T-01-SC | Tampering | npm/pnpm installs | high | mitigate | No new packages; frozen lockfile from 01-01 |
