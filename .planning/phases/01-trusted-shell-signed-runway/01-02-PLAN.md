Routes: `GET /control/status` returns `{ running: true, pid, port, hosts }`; `POST /control/hosts` (zod body `{ cwd, base? }`) calls `registerHost(store, { cwd, base, detectFramework })` and returns `{ host }` or a 422 with the registry error copy; `POST /control/stop` answers 202 then calls `onStop`.

    src/server/daemon.ts: `runDaemon({ home, port })`: create `run/` (0700) and `logs/`; open `run/daemon.lock.db` with `timeout: 0` and hold `BEGIN EXCLUSIVE` for the process lifetime, keeping the connection referenced (on SQLITE_BUSY print `Counterpoint is already running.` and exit 0); create `token` (0600, 32 random bytes hex) if absent and keep only its SHA-256 in memory; remove a stale `run/daemon.sock` only when connecting to it fails; open the store; listen the control app (given `detectFramework` from src/compose.ts) on `run/daemon.sock` via `createAdaptorServer` and chmod the socket 0600; `serve({ fetch, port, hostname: '127.0.0.1' })` — on `EADDRINUSE` write `run/start-result.json` `{ "error": "port-in-use", "port": N }` and exit 1; write `run/daemon.json` `{ pid, port, startedAt }` with the actually bound port (port 0 gives an ephemeral port for tests); on stop or SIGTERM close both servers, remove the socket and daemon.json, release the lock, exit 0. Log JSON lines to stdout (redirected to `logs/daemon.log` by the CLI); never log tokens.
