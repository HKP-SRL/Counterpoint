**Design notes (docs read 2026-11-10; 01-24's SUMMARY has the live auto-mode facts):**
- *Why a script file.* The listing has to classify each value without printing it, which needs a program of a few hundred characters. Typed inline, the model may alter it (the evaluator matches Bash steps by command text). The probe writes the program to `{probeDir}/cp-env-{nonce}.awk` (probe-owned, inside the treatment's working folder, created exclusively with mode 0600), and the step's command stays short and exact: `awk -f '{path}'`. `awk`'s `ENVIRON` array holds exactly the command's environment. macOS ships `/usr/bin/awk` (BWK awk): use only POSIX awk features and avoid regex interval braces; `length()` checks replace them.
- *What the script prints.* One line per variable: the name, a space, the value's length, a space, and one shape word (for `url-userinfo`, then a space and the host class; see "The host class"), chosen in this order:
  - `prefix`: the value starts with `sk-`, `ghp_`, `gho_`, `ghu_`, `ghs_`, `ghr_`, `github_pat_`, `glpat-`, `xoxa-`, `xoxb-`, `xoxp-`, `xoxr-`, `xoxs-`, `AKIA`, `ASIA`, `AIza` or `npm_`;
  - `jwt`: the value starts with `eyJ`, followed by two dot-separated base64url segments;
  - `url-userinfo`: the value holds a `scheme://user:password@` form;
  - `pem`: the value contains `-----BEGIN`;
  - `opaque`: at least 32 characters, only letters, digits and `+/=_-` (no dot), at least one letter and one digit, not starting with `/`, and not a 36-character hex UUID with dashes;
  - otherwise `plain`.
- *Credential-shaped name.* Upper-case the name, split it on every non-alphanumeric character, and flag it when a segment is one of TOKEN, TOKENS, SECRET, SECRETS, PASSWORD, PASSWORDS, PASSWD, PASS, PASSPHRASE, CREDENTIAL, CREDENTIALS, CREDS, KEY, KEYS, APIKEY, AUTH, OAUTH, COOKIE, COOKIES, ASKPASS or PAT, or when the upper-cased name contains TOKEN, SECRET, PASSWORD, PASSWD, PASSPHRASE, CREDENTIAL, APIKEY or ASKPASS anywhere. `SSH_AUTH_SOCK` is flagged (agent socket); `PWD`, `GIT_AUTHOR_NAME` and `CLAUDE_CODE_SESSION_ID` are not.
